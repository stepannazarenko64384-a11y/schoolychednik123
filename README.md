# База данных Яндекс.Учебник (Класс 9Л) — Защищенная версия

Интерактивный сайт для быстрого и удобного поиска логинов и кодов учеников с комплексной многоуровневой защитой от копирования, инспекции и просмотра исходного кода.

---

## 🛡️ Реализованная система защиты (Anti-Inspection & Security)

1. **Блокировка контекстного меню (Right-Click Guard):**
   - Полный перехват правого клика мыши на всех элементах страницы (запрещены меню «Просмотреть код», «Исследовать элемент», «Просмотр кода страницы»).

2. **Перехват горячих клавиш разработчика (Windows & macOS):**
   - `F12` — вызов инструментов разработчика (DevTools)
   - `Ctrl + U` / `Cmd + Option + U` — просмотр исходного кода (`view-source:`)
   - `Ctrl + Shift + I` / `Cmd + Option + I` — инспектор элементов
   - `Ctrl + Shift + J` / `Cmd + Option + J` — консоль JavaScript
   - `Ctrl + Shift + C` / `Cmd + Option + C` — выбор элемента для инспекции
   - `Ctrl + Shift + K` — консоль Firefox
   - `Ctrl + Shift + E` — сетевой монитор
   - `Ctrl + Shift + P` / `Ctrl + Shift + S` — командная панель и сохранение страницы
   - `Ctrl + S` / `Cmd + S` — сохранение веб-страницы на диск
   - `Ctrl + P` / `Cmd + P` — печать в PDF
   - `Shift + F10` / `F1` — контекстные и вспомогательные клавиши

3. **Активный детектор панели разработчика и экран блокировки (DevTools Shield):**
   - Постоянный фоновый мониторинг открытия DevTools (по разнице габаритов окна и дебаггер-бенчмаркам).
   - При попытке открыть инспектор через меню браузера экран моментально блокируется непрозрачным защитным щитом (`🔒 Просмотр кода заблокирован`), а содержимое сайта размывается.
   - Цикл заморозки отладки (`debugger loop`), останавливающий выполнение при попытке анализа скриптов.

4. **Защита от выделения и перетаскивания (Anti-Scraping):**
   - Глобальный запрет выделения текста (`user-select: none`) для всех элементов, кроме строки поиска.
   - Запрет перетаскивания текста, карточек и картинок (`dragstart`).

5. **Изоляция и скрытие данных из глобальной области видимости:**
   - Данные учеников не хранятся в открытом объекте `window` (`window.STUDENTS_DATA` возвращает `undefined`).
   - Одноразовый шлюз десериализации (`Handshake Gateway`), самоуничтожающийся после инициализации интерфейса.
   - Нейтрализация методов консоли (`console.log`, `info`, `warn`, `table` и др.) и периодическая очистка консоли.

6. **Динамический рендеринг структуры (No-HTML in Source):**
   - В статическом файле `index.html` отсутствует разметка карточек и элементов страницы. Вся структура генерируется кодом в памяти браузера, поэтому просмотр исходного кода страницы через браузер или текстовый редактор не раскрывает структуру сайта.

7. **Обфускация и шифрование скриптов:**
   - Код логики и модуль данных сжаты, переменные обфусцированы, комментарии удалены, база учеников упакована в бинарно-замаскированный блоб.

---

## 🚀 Как открыть сайт
Просто дважды кликните по файлу **`index.html`** в этой папке — сайт откроется в любом браузере (Chrome, Edge, Яндекс Браузер, Firefox и др.) без необходимости устанавливать дополнительные программы или локальные серверы.

## ✨ Возможности сайта
1. **Мгновенный умный поиск:**
   - Поиск по имени, фамилии или логину
   - Автоматическое исправление случайного набора на английской раскладке (например, `ctktpytd` найдёт `Селезнев`)
   - Подсветка совпадений жёлтым цветом
   - Горячая клавиша `/` для быстрого перехода к строке поиска
2. **Удобное защищенное копирование:**
   - Кнопка копирования логина (с анимацией и всплывающим уведомлением)
   - Кнопка копирования кода класса (`391689`)
   - Кнопка «Скопировать всё» (копирует ФИО, логин, код и ссылку для входа)
3. **Безопасный переход:**
   - Прямой переход в Яндекс Учебник (`education.yandex.ru/kids/`) с защитой от спуфинга (`noopener noreferrer`).
